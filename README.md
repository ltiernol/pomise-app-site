# Peel public site

Public privacy, support, and privacy-choice pages for **Peel**, operated by Logan Tierno Lauer.

- Site: <https://ltiernol.github.io/peel-app-site/>
- Privacy: <https://ltiernol.github.io/peel-app-site/privacy/>
- Support: <https://ltiernol.github.io/peel-app-site/support/>
- Privacy choices: <https://ltiernol.github.io/peel-app-site/privacy-choices/>

This repository intentionally contains no application source, secrets, support messages, analytics, or user data.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. Every push to `main` updates the public site.

## Operational checklist

- Keep `peel.support@gmail.com` protected by two-factor authentication.
- Check safety and privacy messages within one business day during the pilot.
- Review routine resolved support correspondence for deletion within 12 months.
- Update the effective date and policy whenever Peel's data practices or service providers change.
